drv_radio_sx1262

Configuration

A driver entry gives the bus and the four control lines: spi_bus, cs, rst, dio1, busy, with spi_clock_hz optional.

Three more keys describe the module rather than the transceiver, because only a board profile knows which module is fitted. freq_hz is the band the board is matched and licensed for — 868 MHz in Europe, 915 MHz in North America — and defaults to 915 MHz when absent. tcxo_mv is the reference voltage DIO3 supplies to a module's on-board TCXO; omit it for a module running a plain crystal, which must not be sent the command at all. dio2_rf_switch says DIO2 drives the module's own transmit/receive switch, which is separate from any antenna switch the board puts in front of the module.

Known Issues

No known issues. C driver — RadioLib provides robust LoRa modem support.
